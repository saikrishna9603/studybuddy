🔧 Quick Start

1

Clone Repository

Get the code from GitHub

2

Install Dependencies

Run pip install -r requirements.txt

3

Configure .env

Add your OpenAI and Gemini API keys

4

Start Server

Run python run.py and visit localhost:5000

📋 Installation Code

# Clone the repository git clone https://github.com/saikrishna9603/studybuddy.git cd studybuddy # Create virtual environment python -m venv .venv .venv\Scripts\activate # Windows source .venv/bin/activate # macOS/Linux # Install dependencies pip install -r requirements.txt # Configure environment cp .env.example .env # Edit .env with your API keys (OpenAI, Gemini) # Start the application python run.py # Visit http://localhost:5000
