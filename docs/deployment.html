🚀 Deployment Guide

Deploy StudyBuddy to production with these step-by-step guides

Deployment Architecture

StudyBuddy is a full-stack Flask application that requires:

  • Backend: Python Flask server running 24/7
  • Database: SQLite (or PostgreSQL for production)
  • Frontend: Served by Flask (server-side rendering)
  • APIs: OpenAI + Google Gemini (cloud)
ℹ️ Important: GitHub Pages only hosts static sites. This guide covers deploying the complete Flask backend to cloud platforms.

⭐ Option 1: Railway.app (Recommended)

Cost: $5/month free credit | Setup: 5 minutes | DX: Excellent

Step 1: Create Railway Account

  1. Visit railway.app
  2. Sign up with GitHub (one-click)
  3. Authorize Railway to access your repos

Step 2: Create New Project

  1. Click "Create New Project"
  2. Select "Deploy from GitHub"
  3. Choose the studybuddy repository
  4. Railway automatically detects Flask

Step 3: Configure Environment Variables

In Railway dashboard, go to "Variables" and add:

OPEN_API_KEY = sk-proj-your-key-here GEMINI_API_KEY = your-gemini-key-here GEMINI_MODEL = gemini-1.5-flash SECRET_KEY = generate-strong-random-key FLASK_ENV = production
✅ That's it! Railway will automatically deploy on every push to master branch. Your app goes live at: https://studybuddy-[random].up.railway.app

✅ Option 2: Render.com (Best Free Tier)

Cost: Free tier available | Setup: 10 minutes | DX: Great

Step 1: Create Render Account

  1. Visit render.com
  2. Sign up with GitHub
  3. Authorize Render to access repositories

Step 2: Deploy New Web Service

  1. Click "New +" → "Web Service"
  2. Connect GitHub repository
  3. Configure:
    • Name: studybuddy
    • Environment: Python 3
    • Build Command: pip install -r requirements.txt
    • Start Command: gunicorn app:create_app()

Step 3: Add Environment Variables

In Render dashboard, add these variables:

OPEN_API_KEY = sk-proj-your-key-here GEMINI_API_KEY = your-gemini-key-here GEMINI_MODEL = gemini-1.5-flash SECRET_KEY = generate-strong-random-key
⚠️ Note: Free tier enforces 15-minute inactivity timeout. Upgrade to paid ($7/month) for production use.

🔧 Troubleshooting Deployment

App crashes after deployment

Check the logs in your platform's dashboard. Common issues:

  • Missing environment variables → Add all keys from .env.example
  • Database not initialized → Let the app initialize on first run
  • Dependency version conflict → Check Python version compatibility

Slow API responses

  • OpenAI taking longer → Normal, use Gemini fallback
  • Cold start delays → Upgrade to paid tier to reduce cold starts
  • Database queries slow → Add indexes, consider PostgreSQL

Getting "502 Bad Gateway"

  • App crashed → Check error logs
  • Out of memory → Upgrade instance size
  • Port not listening → Ensure Flask binds to correct port
